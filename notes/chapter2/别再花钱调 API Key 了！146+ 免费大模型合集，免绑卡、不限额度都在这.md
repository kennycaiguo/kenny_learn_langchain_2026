## 四、一键无缝接入：怎么把它们用到工具里？

这是 `awesome-freellm-apis` 仓库最良心的地方——它不仅整理了 API，还在仓库的 `code-examples/` 目录下直接提供了各大 AI 工具的**一键配置代码**。

不管你用什么语言或工具，所有提供商基本都提供了 **OpenAI 兼容的接口**，你只需要替换 `baseURL` 和 `apiKey`。

### Python 快速起步 (以 Groq 为例)

```text
from openai import OpenAI

client = OpenAI(
    base_url="https://api.groq.com/openai/v1",  # 免费，无需信用卡
    api_key="你的_GROQ_KEY",                     # 去 console.groq.com/keys 领
)

response = client.chat.completions.create(
    model="llama-3.3-70b-versatile",
    messages=[{"role": "user", "content": "你好，写一个快排"}],
)
print(response.choices[0].message.content)
```

### Cursor 配置

1. 打开 `Settings` → `Models` → `Add Model`
2. **Model name**: `llama-3.3-70b-versatile`
3. **Base URL**: `https://api.groq.com/openai/v1`
4. **API key**: 填入你的 Groq 免费 Key

### Claude Code 配置

如果你想在终端里用 Claude Code，又不想花官方 Anthropic 的高昂 API 费，可以用 OpenRouter 的接口：

```text
export ANTHROPIC_BASE_URL="https://openrouter.ai/api"
export ANTHROPIC_AUTH_TOKEN="sk-or-v1-你的密钥"
export ANTHROPIC_API_KEY=""  # 留空
```

## 五、使用前的四个注意事项

在你拿着这份清单去薅羊毛之前，有几件事必须提前知晓：

1. **[速率限制](https://zhida.zhihu.com/search?content_id=275489262&content_type=Article&match_order=1&q=速率限制&zd_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3MiOiJ6aGlkYV9zZXJ2ZXIiLCJleHAiOjE3ODg0MDIxMzYsInEiOiLpgJ_njofpmZDliLYiLCJ6aGlkYV9zb3VyY2UiOiJlbnRpdHkiLCJjb250ZW50X2lkIjoyNzU0ODkyNjIsImNvbnRlbnRfdHlwZSI6IkFydGljbGUiLCJtYXRjaF9vcmRlciI6MSwiemRfdG9rZW4iOm51bGx9.0ATDA45fp1WHO42TtBExkGJ9yI9xSOkc27DSNF-dtbg&zhida_source=entity)要做好降级（Retry）**：几乎所有免费 API 都有 RPM（每分钟请求数）限制。写脚本时记得加上退避重试逻辑，遇到 `429 Too Many Requests` 等一下再发，别让程序直接崩了。
2. **多平台组合分散风险**：免费政策随时会变。建议做好 Fallback 策略，比如主用 Groq，备用 GitHub Models 或 Cloudflare，不要死磕一家。
