# kenny_learn_langchain_2026
学习langchain框架

### 注意：

这里的代码里面的大模型一般都使用本地大模型，是用ollama来部署的。

ollama的下载地址：https://ollama.com/download

使用非常简单

下载大模型： 打开严格cmd窗口，输入ollama run 大模型名称，如： ollama run qwen3-vl:latest，第一次会下载，第二次直接调用大模型

查看已经部署的本地大模型： ollama list

删除大模型： ollama rm 大模型名称，如ollama rm qwen3-vl:latest
